# Модель ёмкости и стоимости

Цены — Yandex Cloud на 28.10.2026, с НДС, из официальных страниц тарифов ([Managed PostgreSQL](https://yandex.cloud/ru/docs/managed-postgresql/pricing), [Serverless Containers](https://yandex.cloud/ru/docs/serverless-containers/pricing), [MapKit](https://yandex.ru/dev/tariffs/doc/ru/mapkit/prices/index.md)). Цена диска, CDN и Postbox в расчёт не вошла — сверить в калькуляторе перед запуском. Все цифры — оценка порядка величины, не счёт.

## Допущения

| Параметр | Значение | Откуда |
|---|---|---|
| Запросов к API на активного пользователя в день | 30, из них 12 — батчи шагов | синк раз в час в фоне при изменении + 2 открытия по ~9 запросов |
| Пиковый час | 10 % суточного трафика, внутри часа ×2 | вечерняя активность; jitter 0–10 мин сглаживает «ровно в :00» |
| Средняя длительность запроса | 100 мс при 1 vCPU, 1 ГБ | с округлением тарификации до 100 мс |
| Строка `daily_steps` с индексом | ~190 байт | замер ревью на 4,2 млн синтетических строк (таблица + PK) |
| Строк в год | DAU × 365 × 1,3 | часть пользователей ходит не каждый день, бэкфилл дней |
| Пушей | ≤ 2 на пользователя в день | требование ТЗ |

## Нагрузка

| DAU | Запросов/сутки | Средний RPS | Пиковый RPS | `daily_steps` за год | Пушей/сутки, макс. |
|---:|---:|---:|---:|---:|---:|
| 1 000 | 30 тыс. | 0,3 | ~2 | 0,5 млн строк, 0,09 ГБ | 2 000 |
| 10 000 | 300 тыс. | 3,5 | ~17 | 4,7 млн, 0,9 ГБ | 20 000 |
| 100 000 | 3 млн | 35 | ~170 | 47 млн, ~9 ГБ | 200 000 |

Замеры ревью на синтетике (20 тыс. пользователей, 4,2 млн строк шагов): синк одного дня — 1,5 мс, батч из 32 дней — 15 мс, сводка и «осталось N дней» — 0,3 мс.

Вывод: даже 100 тыс. DAU — небольшая нагрузка для PostgreSQL. Узкое место будет не CPU, а число соединений от serverless-экземпляров — его снимает встроенный пулер Managed PostgreSQL в режиме транзакций (у asyncpg тогда отключается кэш подготовленных запросов, это учтено в настройках этапа 2).

## Уровни инфраструктуры

| Уровень | Когда | PostgreSQL | API | Прочее | Итого, ₽/мес (без диска и CDN) |
|---|---|---|---|---|---|
| **0. Разработка** | этапы 1–11 | s3-c2-m8, 1 хост ≈ 5 700 | Serverless Containers ≈ 0 (в бесплатном объёме) | Object Storage, Lockbox — копейки | **~6 тыс.** Можно дешевле на burstable-хосте — проверить в калькуляторе |
| **1. Запуск** | до ~5 тыс. DAU | s3-c2-m8, 1 хост + ежедневные бэкапы (входят) ≈ 5 700 | ≈ 200–1 500 + 1 подготовленный экземпляр против холодного старта ≈ 1 200 | CDN, Postbox | **~8–10 тыс.** |
| **2. Рост** | 5–30 тыс. DAU или первые жалобы на простой | 2 хоста s3-c2-m8 (HA) ≈ 11 400 | ≈ 2 500–7 000 | + Valkey для лимитов, если PG-лимиты станут заметны | **~15–20 тыс.** |
| **3. Масштаб** | 30–100 тыс. DAU | 2–3 хоста s3-c4-m16 ≈ 23–34 тыс. | ≈ 25 тыс. на serverless → дешевле группа ВМ / Managed Kubernetes | Message Queue для пушей | **~50–70 тыс.** |

Переход между уровнями — по метрикам, не по календарю: p95 синка > 300 мс, CPU БД > 60 % в пике, очередь пушей не успевает за 5 минут.

Это сознательно отличается от плана из предыдущего шага (HA-кластер + Redis + брокер с первого дня, ~25–30 тыс. ₽/мес): при точке безубыточности ~220 месячных подписчиков такие постоянные расходы съели бы всю выручку до появления аудитории. Архитектура (stateless API, outbox, `rate_limits` за интерфейсом) позволяет добавить каждый компонент без переделки кода.

## Карта — отдельная крупная статья

| Вариант | До 1 000 DAU карты | 5 000 DAU | 20 000 DAU |
|---|---|---|---|
| Yandex MapKit, коммерческая лицензия, помесячно | бесплатно — **только если приложение не считается платным** (см. R-02) | 20 800 ₽/мес | 58 500 ₽/мес |
| MapLibre + векторные тайлы OSM на Object Storage + CDN | трафик CDN | трафик CDN | трафик CDN |

DAU карты — это пользователи, открывшие карту, а не все пользователи: главный экран показывает прогресс без карты (иллюстрация пути), карта — по нажатию. Это сокращает DAU карты примерно вдвое при любом выборе.

## Пуши

RuStore не публикует числовой лимит RPS для отправки ([документация](https://rustore.ru/help/sdk/push-notifications/send-push-notifications)): есть ошибка «слишком много запросов» без порога. Поэтому воркер шлёт с ограничением параллельности и экспоненциальной паузой на 429. 200 тыс. пушей в сутки при равномерной отправке — ~2–3 в секунду.
