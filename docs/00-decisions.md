# Журнал решений «Путника»

Формат: что решили, кто решил, почему, что это меняет. Новые решения дописываются снизу.

## Принятые решения

| # | Дата | Решение | Кто | Следствие |
|---|------|---------|-----|-----------|
| D-01 | 28.10.2026 | Бэкенд — Python 3.12 + FastAPI (async), SQLAlchemy 2 + asyncpg, Alembic | владелец | Один язык для API и воркеров, быстрый старт, OpenAPI из коробки |
| D-02 | 28.10.2026 | Клиент — Flutter, чистая архитектура, Riverpod (+ riverpod_generator) | владелец | DI и состояние в одном механизме, работает вне дерева виджетов (нужно фоновому сбору шагов) |
| D-03 | 28.10.2026 | Шаги: Health Connect — основной источник, TYPE_STEP_COUNTER — запасной | владелец | На устройствах без Google Play и Android ≤ 13 Health Connect недоступен, без запасного датчика часть аудитории RuStore осталась бы без шагов |
| D-04 | 28.10.2026 | Спрайты миплов и NPC — заглушки на время разработки | владелец | Этап 1 генерирует простые плейсхолдеры; ключи `sprite_key` стабильны, замена = загрузка файлов в Object Storage |
| D-05 | 28.10.2026 | Бесплатные миплы: «Путник» и «Путница» (идут). Остальные 6 — премиум | владелец | `content/meeples.json`, поле `is_free` |
| D-06 | 28.10.2026 | Бесплатный маршрут один — самый короткий: «Царицыно — Коломенское» (№2, 9 км). Остальные 5 — премиум | владелец | **Меняет ТЗ** (там бесплатные 1–3). Учтено в `content/routes/*.json` |
| D-07 | 28.10.2026 | Аккаунта Yandex Cloud, домена и политики ПДн нет. Политика пишется с нуля по законодательству РФ | владелец | Этап 11: политика, согласие, уведомление в РКН. Домен и облако нужны раньше — к этапу 2 (письма, OAuth redirect) |
| D-08 | 28.10.2026 | День шагов считается по местному времени пользователя, пояс хранится в профиле | владелец | `users.timezone`, `daily_steps.tz`; «сегодня» вычисляет сервер, клиенту не верим |
| D-09 | 28.10.2026 | Прогресс маршрута = накопленные зачтённые шаги, не координаты | архитектор | Сервер не знает и не хранит, где пользователь; позицию мипла на линии считает клиент |
| D-10 | 28.10.2026 | NPC не симулируются фоном: снимок состояния + ленивое детерминированное «дошагивание» при чтении | архитектор | Ноль фоновой нагрузки, одинаковый результат на любом устройстве |
| D-11 | 28.10.2026 | Зачёт шагов — функция `sync_daily_steps` в PostgreSQL | архитектор | 1 round-trip, атомарность под блокировкой пользователя, покрыто SQL-тестами |
| D-12 | 28.10.2026 | Пробный период — серверный: 7 дней с регистрации, без карты, один раз на аккаунт | архитектор | Не зависит от настроек триала в RuStore. Риск мультиаккаунтов принимаем в MVP |
| D-13 | 28.10.2026 | Инфраструктура MVP «по средствам»: один хост PostgreSQL, Serverless Containers, outbox-таблицы вместо брокера, лимиты частоты в PG вместо Redis | архитектор | **Пересматривает план из предыдущего шага** (HA-кластер, Redis, очередь). Точка безубыточности ~220 подписчиков не выдержит 25–30 тыс. ₽/мес на инфраструктуру. Переход на следующий уровень — по порогам из `03-capacity.md` |
| D-14 | 28.10.2026 | Пуши — RuStore Push SDK | архитектор | Работает на устройствах с установленным RuStore; без него — только внутриигровые уведомления |
| D-15 | 28.10.2026 | Сверх длины маршрута шаги не переносятся на следующий маршрут, но идут в статистику и медали за дистанцию | архитектор | Простое правило, без «долга» шагов |
| D-16 | 28.10.2026 | Покупка подписки днём засчитывает сегодняшние сверхлимитные шаги | архитектор | Сильный аргумент на пейволле: «купи — и 3 400 шагов сегодня зачтутся» |
| D-17 | 28.10.2026 | По итогам ревью: блокировка пользователя `FOR NO KEY UPDATE`; медали, лента и пуши — в транзакции синка от абсолютного состояния | ревью backend + scalability | Исправлен воспроизводимый deadlock «бонус → синк»; события не теряются при сбоях |
| D-18 | 28.10.2026 | Лента друзей: только дата, задержка 6 ч, процент маршрута — снимок прошлого дня; `share_activity` по умолчанию включён (ТЗ требует видимость маршрута друзьям), выключается в настройках | ревью security | По ленте нельзя восстановить распорядок дня |
| D-19 | 28.10.2026 | Удаление аккаунта: мягкое сразу с удалением дружб и сменой кода; 30 дней на восстановление входом; затем полное. Подписки обезличиваются, не удаляются | ревью security + backend | 152-ФЗ и закон о бухучёте одновременно |
| D-20 | 28.10.2026 | Покупка привязывается к аккаунту через `account_ref`; вебхуки — только сигнал, состояние перечитывается у провайдера | ревью security | Чужую покупку не привязать, повтор вебхука безвреден |
| D-21 | 28.10.2026 | Шаги дня считаются в поясе, в котором день открылся; новый пояс приходит в каждом батче | ревью backend | При перелётах шаги не считаются дважды |
