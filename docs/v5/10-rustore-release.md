# Публикация в RuStore: требования и чек-лист

Источник: [RuStore — публикация приложения](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication) (владелец прислал 28.11.2026; выжимка снята в тот же день). Правила модерации — отдельная страница RuStore, перед отправкой прочитать её тоже.

## Что требует RuStore

**Доступ.** Приложение добавляет только Владелец компании в RuStore Консоли («Приложения» → «Добавить приложение» → «Загрузить версию»). Версии могут загружать Владелец, Администратор, Релиз-менеджер, Разработчик. Тип — «Универсальный».

**Сборка.** APK или AAB до 5 ГБ.
- Первая версия: подписана сертификатом, имя пакета уникально.
- Следующие: та же подпись и то же имя пакета, номер версии (versionCode) больше прошлого.
- Загруженный файл обрабатывается; ошибки видны после обработки. Не отправленный на модерацию файл удаляется через 14 дней.
- Можно приложить отдельный файл для Huawei/Honor (необязательно).

**Тексты карточки.**
| Поле | Ограничение |
|---|---|
| Название | до 30 символов, уникальное |
| Краткое описание | до 80 символов |
| Подробное описание | до 4 000 символов (до разворачивания видно 2 000) |
| Что нового | для каждой версии |
| Категория | для игр — ещё маркировка внутриигрового контента |
| Возрастное ограничение | из списка |
| Теги | до 5, необязательно |
| Контакты | хотя бы одно: почта, группа ВК, сайт или МАКС |
| Безопасность данных | категории и типы данных, чувствительные разрешения |

**Медиа.**
- Иконка 512×512, PNG/JPG до 3 МБ, сплошной фон без прозрачности.
- Скриншоты телефона: минимум 3 (до 10 за раз), PNG/JPG до 3 МБ, не больше 2160×3840.
- Видео VK (необязательно), FAQ до 10 пар (необязательно).

## Что у нас есть и чего нет (на 0.7.9)

| Пункт | Состояние |
|---|---|
| Имя пакета | `ru.putnik.app` — проверить уникальность при создании |
| Релизная подпись | **Нет.** Сейчас APK подписан тестовым ключом `putnik-test.jks`, он лежит в репозитории. Нужен новый релизный ключ, храним только в секретах GitHub и у владельца. Потерять его нельзя: без него не выйдет ни одно обновление |
| versionCode | 1000 + номер запуска CI — растёт сам (V5-51) |
| Иконка 512×512 | Есть исходник «Хвост кита» (`tools/art/app_icon.*`), выгрузить PNG без прозрачности |
| Скриншоты | Нет — снять 3–8 экранов: пролог, путь, событие с духом, карта, книжка, утренняя мысль |
| Тексты карточки | Нет — написать название (≤30), краткое (≤80), подробное (≤4 000) |
| Безопасность данных | Шаги (датчик, Health Connect), имя и почта, аналитика AppMetrica; разрешения: физическая активность, уведомления, Health Connect READ_STEPS |
| Возраст и маркировка | Решить: в игре есть смерть героя (без жестокости), фольклорные духи, покупки монет |
| Оплата | Подписка и монеты пока в тестовом режиме: до публикации — RuStore Pay SDK и сервер проверки покупок; тестовые переключатели убрать |
| Ссылка «Поделиться» | `kAppLink` — заглушка `https://www.google.com/`, заменить на ссылку карточки RuStore |
| Политика конфиденциальности | Отдельного поля на странице нет, но нужна по 152-ФЗ (сбор имени и почты) — проверить в правилах модерации |
| Тестовые функции | Убрать из релиза: кнопку «Дальше», ручной ввод до 100 000 шагов, тестовый переключатель подписки |
