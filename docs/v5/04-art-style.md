# Этап 0.5 · Арт-стиль «Путника»

Статус: MVP-графика готова. Вся графика нарисована с нуля кодом (`tools/art/*.py` → `app/assets/art/`), без внешних изображений, шрифтов, клипарта и чужих стилей. Права чистые.

## Настроение
«Волшебное в обыденном»: ночь, тёплый свет окон и костров, северное сияние вдали. Таинственно, по-доброму, местами смешно (коты, совы, домовой с кружкой), без хоррора: у существ мягкие формы, глаза-прищур, румянец.

## Приёмы
* Плоские слои-силуэты, 2–4 плана глубины, воздушная перспектива (дальнее светлее).
* Мягкие линейные градиенты неба/воды; свечение — радиальный градиент к прозрачности.
* Без обводок у пейзажей; допустимы тонкие «гравюрные» штрихи (opacity 0.1–0.3), золотой кант на резьбе изб и рамках.
* Один тёплый источник света на сцену (окно, фонарь, костёр) + холодный лунный/сияние.
* Существа — в медальоне Ø112 с двойным золотым кольцом и четырьмя звёздочками; содержимое обрезано по кругу геометрически.
* Путник — Сергей v2 (русый, витраж): см. раздел «Герой (v5.3)» ниже.

## Технические правила (flutter_svg)
Только `path, rect, circle, ellipse, polygon, polyline, g, linearGradient, radialGradient, stop, defs`. Нельзя: `filter, mask, clipPath, pattern, text, image, foreignObject, use`, CSS и `style`. Цвет — атрибутами `fill/stroke/opacity`. Задан `viewBox`, без размеров в пикселях, файл ≤ 25 КБ.

## Витраж (v5.3)
С v5.3 все картинки — «фрески из стекла»: сцены (360×200), существа (медальоны 120×120, свинцовое кольцо вместо золотого), финал, слайды онбординга. Раздел выше («Палитра Атлас», золотые кольца) описывает прежнее плоское «сырьё»; в приложение идёт витраж.

**Палитра стекла:** свинец `#070B10`; бирюза `#2BC4BA`, глубокий синий `#1B4F8C`, ультрамарин `#2B3E9E`, изумруд `#1F9E6B`, фиолет `#5B3FA0`, коралл `#C8454F`, янтарь `#F0A24A` (только окна, костры, огни — малые осколки), молочное `#EDE6D2`, ночь `#0B1424`. Каждый осколок снапается к рампе этих оттенков (7 ступеней яркости), ≤ ~27 цветов на картинку. Больших жёлтых плоскостей нет: крупные тёплые формы уходят в коралл/молочное.

**Приёмы:** осколок = видимая часть исходной фигуры (карта идентификаторов примитивов из Chromium), крупные формы (небо, вода) режутся k-means-ячейками на грани; цвет — по рангу яркости (градиентная карта ночь → ультрамарин → синий → бирюза → молоко) с усилением контраста между соседями; радиальный градиент на осколке «светлее к краю»; стекло полупрозрачное (α≈0,88) поверх свинцовой подложки с тёплыми/молочными свечениями у окон, костров и луны (задняя подсветка + лёгкий ореол сверху); блики — светлые треугольники у граней, обращённых к свету; звёзды — ромбики; тонкие линии сырья (камыш, провода, столбы, дождь) — «роспись» свинцом/молоком. Свинец: 1,4 на всех границах, 2,6 на границах крупных форм, рама 4. Только path/rect/circle/g/gradients, ≤ 25 КБ.

**Пересборка:** `python3 tools/art/build.py --glass --sheet /tmp/art_sheet.png` (≈1 мин; `--glass-only scenes/hut,finale` — часть). Сырьё пишется в `tools/art/raw/` (генераторы `scenes.py`, `creatures.py`, `extras.py`), конвертер — `tools/art/glassify.py` (запуск отдельно: `python3 tools/art/glassify.py [имя]`), параметры групп — словарь `CONFIG` в нём. Без `--glass` картинки не перезаписываются. Герой/иконка/заставки/предметы ведут свои скрипты (`hero_glass.py`, `items_glass.py`). build.py проверяет запрещённые элементы и размер для всех SVG в `app/assets/art`.
