# План теста на круге близких (Продакт + QA + Аналитик)

## Цель и критерии

Проверить петлю удержания: шаги → путь → события → выживание → утренняя мысль.

| Метрика | Цель | Где смотреть |
|---|---|---|
| D7 (зашли на 7-й день) | ≥ 35–40 % | AppMetrica → Удержание |
| Прошли главу 1 | ≥ 60 % | событие `chapter_done` с `chapter = 1` / установки |
| Готовы платить 149 ₽ | ≥ 30 % ответов «да» и «скорее да» | событие `survey_pay_149` |
| Развёрнутые отзывы | ≥ 5 | интервью, Telegram-чат |

Похвала «круто!» без цифр не считается.

## Ход теста (4 недели)

1. **Пред-тест (2–3 дня, 2–3 человека).** Ставим APK, проверяем, что шаги идут на разных телефонах (особенно Xiaomi, Samsung, Honor), что уведомления приходят, что ничего не падает. Правки — новой сборкой.
2. **Тест (4 недели, 10–20 человек).** Раздача APK в Telegram-чате теста. Никаких подсказок по игре — смотрим, понятно ли без нас.
3. **Еженедельно** (Продакт): цифры, 3 главных наблюдения, список правок.
4. **В конце**: 5–7 коротких интервью по 15 минут; решение «масштабируем / меняем ядро».

## Карта событий AppMetrica

| Событие | Когда | Параметры |
|---|---|---|
| `app_open` | запуск | has_journey |
| `onboarding_slide` | слайд онбординга | n |
| `profile_saved` | имя и почта | has_email, consent |
| `perm_activity`, `perm_health_connect`, `perm_notifications` | разрешения | granted, status |
| `journey_start` | старт пути | sensor, health_connect |
| `steps_synced` | пришли новые шаги | added, sensor_today, hc_today |
| `goal_reached`, `login_claimed` | монеты за цели и заход | coins |
| `event_shown` | остановка-событие | id, kind, chapter |
| `event_choice` | выбор | id, choice, risk, died |
| `quest_started` | старт квеста | id |
| `place_arrived` | привал | id |
| `buy`, `item_used` | рынок, рюкзак | item, price |
| `death`, `respawn` | смерть и возвращение | cause, chapter, deaths |
| `chapter_done` | конец главы | chapter |
| `thought_read`, `thought_answered` | утренняя мысль | day, open, length |
| `notif_opened` | приложение открыто из уведомления | id, kind: morning / stop / delay / evening / low_stats |
| `bonus_started`, `bonus_noticed` | начало «сытой серии», герой стал «приметен» | km |
| `survey_pay_149` | опрос после главы 1 или 8-го дня | answer: yes / likely / unlikely / no |
| `journey_reset`, `journey_finished` | сброс, финиш | days |

Воронка онбординга: `app_open` → `onboarding_slide n=4` → `profile_saved` → `perm_activity granted` → `journey_start`.
Воронка главы: `journey_start` → `place_arrived id=klin` → `chapter_done chapter=1` → `place_arrived id=valday` → `chapter_done chapter=2`.

## Чек-лист пред-теста (QA)

- [ ] Установка APK на Android 10, 12, 14; первый запуск без ошибок.
- [ ] Онбординг: 4 слайда, профиль (без почты и с почтой), согласие обязательно.
- [ ] Разрешение «Физическая активность»: после согласия в течение 15 минут прогулки шаги на главной растут.
- [ ] Health Connect: если установлен — разрешение, строка «Health Connect N» показывает шаги; если не установлен — кнопка «Установить» открывает магазин.
- [ ] Шаги идут в фоне: закрыть приложение, пройти 1 000 шагов, открыть через 20+ минут — шаги учтены.
- [ ] Не открывать приложение сутки: вчерашние шаги попали во вчерашний день (цели дня засчитаны). Если нет — на этом телефоне фоновое чтение датчика заблокировано: подключить Health Connect.
- [ ] Обновление APK поверх старой версии (без удаления) сохраняет прогресс.
- [ ] Перезагрузка телефона не обнуляет и не задваивает шаги дня.
- [ ] Первое событие на Красной площади появляется после ~1,5 км пути Сергея (≈ 400 реальных шагов).
- [ ] Событие: выбор с «Нужно: Хлеб» неактивен без хлеба; знак опасности у смертельного варианта.
- [ ] Привал: покупка, «рюкзак полон», «не хватает монет», «Идти дальше».
- [ ] Смерть: экран, откат, потеря части припасов, на повторном отрезке нет повторных событий.
- [ ] Утренняя мысль: уведомление в 8:00, ответ сохраняется, виден в «Мыслях на дороге».
- [ ] Событийные уведомления не приходят с 22:00 до 08:00 и не больше 3 в день.
- [ ] Карта: «Весь путь» / «Рядом», масштаб пальцами, герой на линии.
- [ ] Монеты за заход: кнопка один раз в день.
- [ ] Опрос появляется после главы 1 или на 8-й день, один раз.
- [ ] Настройки → «Журнал событий статистики» показывает события; с ключом — «отправляется в AppMetrica».
- [ ] Сброс пути возвращает на онбординг.
