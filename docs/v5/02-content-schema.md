# Этап 0 · Схема контента

Владельцы: Архитектор (формат), Квест-архитектор (семантика), Контент — Нарратив и Сюжетный совет.
Валидатор: `tools/content/validate.py` — запускается в CI, ни одна сборка не пройдёт с битым контентом.

Все файлы — `app/assets/content/`. Тексты — только здесь; числа — только в `balance.json`. В событиях вместо чисел стоят **уровни** (`small`, `medium`, `large`), их значения задаёт баланс.

## 1. Файлы

| Файл | Что внутри |
|---|---|
| `chapters.json` | главы: id, название, отрезок, сезон, вступление, финал |
| `places.json` | точки маршрута (города, деревни, ориентиры), координаты, тип рынка |
| `items.json` | предметы: id, название, описание, тип, эффект (уровнем), цена (уровнем) |
| `creatures.json` | реестр существ: id, имя, регион, характер, режимы контакта |
| `events_ch1.json`, `events_ch2.json` | авторские события глав, привязанные к точкам |
| `events_random.json` | пул случайных событий (теги главы/биома) |
| `quests.json` | многошаговые квесты (квесты главы, «Попутчик») |
| `thoughts.json` | утренние мысли |

## 2. Событие

```json
{
  "id": "ch1_klin_dog",
  "kind": "regional",
  "chapter": 1,
  "anchor": { "after": "klin", "km": 6 },
  "once": true,
  "art": "forest",
  "creature": null,
  "title": "Пёс у остановки",
  "text": "Текст ситуации, 300–700 знаков. От третьего лица или нейтрально; внутренний голос Сергея — курсивом через _подчёркивания_.",
  "choices": [
    {
      "id": "feed",
      "text": "Поделиться хлебом",
      "requires": { "item": "bread" },
      "risk": "none",
      "outcomes": [
        { "weight": 3, "text": "Что случилось (100–300 знаков).", "effects": { "remove": { "bread": 1 }, "coins": "small", "flag": "dog_friend" } },
        { "weight": 1, "text": "...", "effects": { "remove": { "bread": 1 } } }
      ]
    },
    { "id": "pass", "text": "Пройти мимо", "risk": "none", "outcomes": [ { "weight": 1, "text": "...", "effects": {} } ] }
  ]
}
```

### Поля

* `kind`: `random` | `regional` | `chapter` | `creature` | `companion`.
* `anchor` (для авторских): `after` — id точки из `places.json`, `km` — игровые километры после неё (0–200). Случайные события якоря не имеют; у них есть `tags`: `["ch1", "forest", "road", "village", "water", "night", "rain"]` и необязательный `minChapter`/`maxChapter`.
* `once`: событие происходит один раз за игру (все авторские — `true`).
* `art`: ключ иллюстрации (`forest`, `field`, `river`, `lake`, `village`, `town`, `road`, `night`, `rain`, `swamp`, `bathhouse`, `hut`, `campfire`, `station`).
* `creature`: id существа из `creatures.json` или `null`.
* `choices`: 2–3 варианта. Почти всегда есть мирный вариант «пройти мимо», кроме уникальных квестов главы.
  * `requires` (необязательно): `{ "item": "bread" }` — предмет в рюкзаке; `{ "coins": "small" }` — монеты; `{ "flag": "dog_friend" }` — ранее поставленный флаг. Если требование не выполнено, вариант виден, но неактивен с подсказкой.
  * `risk`: `none` | `low` | `high` | `fatal`. `fatal` — среди исходов есть смерть; в интерфейсе стоит знак опасности.
  * `outcomes`: взвешенные исходы, движок выбирает один по `weight`.

### Эффекты исхода

| Ключ | Значение | Пример |
|---|---|---|
| `coins` | уровень (`small`/`medium`/`large`) или `"-small"` и т. п. | `"coins": "medium"` |
| `satiety`, `water`, `warmth` | уровень со знаком | `"warmth": "-medium"` |
| `give` | предметы | `{ "tea": 1 }` |
| `remove` | предметы | `{ "bread": 1 }` |
| `delay` | уровень задержки: `short` (≈2 ч) / `medium` (≈6 ч) / `long` (≈12 ч) реального времени | `"delay": "medium"` |
| `detour` | уровень ответвления: `short` (≈3 км) / `medium` (≈6 км) / `long` (≈10 км) игрового пути | `"detour": "short"` |
| `detour_end` | id события, которое покажется в конце ответвления | `"detour_end": "ch1_les_return"` |
| `shortcut` | уровень срезки — герой сразу продвигается вперёд | `"shortcut": "short"` |
| `flag` | поставить флаг (строка или список) | `"flag": "met_leshy"` |
| `quest_start` | id квеста | `"quest_start": "q_poputchik"` |
| `quest_var` | изменить переменные активного квеста | `{ "trust": 1 }` |
| `death` | `true` — герой погибает (только у вариантов с `risk: fatal`) | |
| `bonus_reset` | `true` — сбросить «сытую серию» (обокрали, напугали) | |

Пустой `effects: {}` допустим: исход только текстом.

## 3. Квест (многошаговый)

```json
{
  "id": "q_poputchik",
  "kind": "companion",
  "title": "Попутчик",
  "companion": { "name": "Витя", "desc": "..." },
  "steps": [
    { "id": "s1", "at_km": 4,  "event": { ...событие без anchor... } },
    { "id": "s2", "at_km": 11, "event": { ... } },
    { "id": "s3", "at_km": 19, "event": { ... } },
    { "id": "final", "at_km": 26, "branches": [
        { "if": { "trust": ">=2" }, "event": { ... подарок ... } },
        { "if": {}, "event": { ... ограбление ... } }
    ] }
  ]
}
```

* Квест стартует эффектом `quest_start` у события. `at_km` — игровые км от точки старта квеста.
* Переменные квеста — целые числа, меняются `quest_var`. Условия ветки: `">=2"`, `"<=0"`, `"==1"`. Первая подходящая ветка выигрывает, ветка с пустым `if` — запасная и стоит последней.
* Если герой погиб, активный квест-попутчик прерывается.

## 4. Утренняя мысль

```json
{
  "id": "t01",
  "day": 1,
  "quote": "Текст цитаты в собственном переложении",
  "author": "Марк Аврелий",
  "source": "Размышления, книга II, 1",
  "license": "собственное переложение; оригинал — общественное достояние",
  "text": "Рассуждение Сергея, 100–200 слов, от первого лица. Можно подстановки: {place} — последняя точка, {chapter} — название главы, {km_left} — км до Териберки, {weather} — погода словом.",
  "ending": "open",
  "question": "Вопрос игроку, если ending = open"
}
```

`ending`: `closed` или `open` (развилка с вопросом). Открытых не меньше трети.

## 5. Точка маршрута

```json
{ "id": "klin", "name": "Клин", "lat": 56.331, "lon": 36.729, "kind": "town", "market": "town", "chapter": 1,
  "desc": "Короткая справка о месте (100–250 знаков) — что увидит Сергей." }
```

`kind`: `start` | `city` | `town` | `village` | `landmark` | `finish`. `market`: `city` | `town` | `village` | `none` — набор товаров и наценка задаются балансом.

## 6. Стиль текстов (обязателен для всех авторов)

* Сергей — «он» в описаниях событий, «я» — в утренних мыслях. Мужской род везде.
* Тон — «волшебное в обыденном»: таинственно, тепло, местами смешно. Без хоррора, жестокости, мата, политики, рекламы брендов.
* Существа — соседи по миру со своим характером и правилами, а не монстры. Фольклорные детали — достоверные (проверяет Этнограф).
* Современная Россия: трассы, «Пятёрочка» без названия, электрички, дачи, придорожные кафе, связь пропадает.
* Никаких реальных живых людей и названий компаний.
