## 0. Коротко

* **6 слайдов** (≈ 30 с) объясняют суть: идёшь ты — идёт Сергей, 1 шаг = 5 шагов, 2 099 км до Териберки, сытость/вода/тепло, духи, утренняя мысль, всё на телефоне.
* **Онбординг в 4 этапа** с полосой прогресса: Знакомство (имя) → Шаги (активность, уведомления, Health Connect, источники) → Рюкзак (снаряжение до 3 + еда до 5) → Пролог.
* **Первый шаг у Кремля** — живой счётчик: человек видит, что шагомер работает и Сергей сдвинулся.
* **Тур по главной** — 5 подсветок подряд (карта, следующее место, показатели, бонус, вкладка «Герой»), дальше **подсказки по случаю**: выбор с риском, журнал, красная зона и смерть, первая смена зоны.
* Время до начала пути: 2,5–4 мин; самый короткий путь (пропуск слайдов с 3-го, «Как посоветовал бы бывалый», пропуск пролога) — около минуты.

## 1. Принципы

1. **Суть за 30 секунд.** Каждый слайд — одна мысль: заголовок, 1–2 предложения (≤ 140 знаков) и бирюзовая «плашка-факт», которую можно прочитать за секунду, даже не читая абзац.
2. **Сначала «зачем», потом системный диалог.** Одно разрешение — один экран. Отказ не тупик: всегда есть «другой путь» и «позже».
3. **Честность.** Шаги до старта не засчитываются — так и пишем. Риск в выборах виден заранее. Смерть — откат, а не конец.
4. **Подсказка в момент встречи, а не лекция.** В общий тур попадает только то, что видно на главной в первую минуту. Остальное — один раз, когда случилось впервые.
5. **Офлайн.** Весь поток работает без сети, ничего не отправляет, кроме событий аналитики (если есть ключ и согласие).
6. **Цвет.** Никакого жёлтого текста: акцент — `Palette.accent` `#3FD6CC`, глубокая бирюза `Palette.accentDeep` для рамок; фон `#0E1621`, текст `#E9DFC8`, вторичный `#9BA7B4`. Кнопки — бирюзовые с тёмным текстом.

### 3.3 Поведение

* Листание свайпом и кнопкой «Дальше» (`PageController.nextPage`, 250 мс, `easeOut`; при `MediaQuery.disableAnimations` — `jumpToPage`).
* «Пропустить» видно только на I3–I5: первые два слайда — суть игры, без них остальное непонятно; на I6 вместо пропуска главная кнопка. «Пропустить» → сразу O1 (не на I6).
* Системное «Назад»: на I2–I6 — предыдущий слайд, на I1 — выход из приложения (стандарт Android).
* «Собраться в путь» на I6 и «Пропустить» пишут `introDone = true`, `onboardingStep = 'profile'`.
* Повторно вступление не показывается. Из настроек — «Как играть» (§6.5) в режиме просмотра: те же слайды, «Пропустить» на всех, последняя кнопка «Закрыть», флаги не меняются.

### 3.4 Аналитика

`intro_slide_viewed{n}` — при первом показе слайда за сессию; `intro_skipped{from}` — нажатие «Пропустить» на слайде `from`; `intro_done{skipped, seconds}` — выход из вступления любым способом. Старое `onboarding_slide{n}` удалить (заменено).

## 4. Онбординг O1–O7

### 4.0 Общие элементы

* **AppBar:** «←» (назад на предыдущий шаг), заголовок = название этапа.
* **Полоса этапов** под AppBar: 4 сегмента 4 dp с подписями «Знакомство · Шаги · Рюкзак · Пролог». Текущий — `accent`, пройденные — `accentDeep`, будущие — `#2A3B4F`. Пропущенные экраны не меняют полосу (этапы, а не экраны — полоса не «прыгает»). Semantics: «Этап {n} из {total}: {name}».
* **Кнопки** — внизу, 52 dp, отступы 24 dp; главная — `FilledButton`, второстепенная — `TextButton` бирюзовым.
* **Шаг сохраняется** при входе на экран: `profile.onboardingStep = '<имя>'` (§8). Закрыли приложение — вернёмся сюда же.
* **Разрешения перечитываются** при возврате в приложение (`didChangeAppLifecycleState → refreshPermissions`, уже есть): если пользователь включил разрешение в системных настройках, экран сам показывает «готово» и через 600 мс идёт дальше.
* Событие `onboarding_step{name, back}` — при каждом показе экрана (`back = true`, если пришли кнопкой «назад»).

Правила: имя ≥ 2 символов после `trim` (ошибка показывается после ухода из поля, а не на первой букве); почта пустая или по маске; согласие отмечено. Клавиатура: имя — `TextCapitalization.words`, `TextInputAction.next` → почта (`emailAddress`, `done`). По «Дальше» — `saveProfile(...)` (событие `profile_saved` уже есть) → O2. Имя используется в F1 («Ну что, Аня, пойдём?»).

### 4.2 O2 · «Физическая активность»

| Элемент | Ключ | Текст |
|---|---|---|
| Витраж (150 dp, по желанию) | — | `intro_2_steps.svg`, обрезка `cover` |
| Заголовок | `onbActTitle` | Разреши считать шаги |
| Текст | `onbActBody` | Android спросит про «Физическую активность». Это встроенный шагомер: без GPS и геолокации, батарею почти не тратит. |
| Строка про батарею (карточка ⓘ) | `onbBatteryLine` | На Xiaomi, Huawei и Honor разреши «Путнику» работу в фоне — иначе шаги будут приходить с опозданием. |
| Кнопки | `permAllow` (есть) / `onbActLater` | Разрешить / Не сейчас |
| Разрешено (600 мс, затем дальше) | `onbActGranted` | ✓ Шагомер подключён |
| Отказ (S1) | `onbActDenied` | Без этого разрешения шагомер молчит, и Сергей стоит. Можно спросить ещё раз или подключить Health Connect. |
| Отказ «навсегда» (S1) | `onbActBlocked` | Android больше не спрашивает. Включи «Физическую активность» вручную в настройках приложения. |
| Кнопки S1 | `onbRetry` · `onbOpenSettings` · `permContinueAnyway` (есть) | Спросить ещё раз (или Открыть настройки при «навсегда») · «Подключить Health Connect» = `onbHcConnect` + название · Продолжить без шагов |

* «Разрешить» → `requestActivityPermission()` (есть, событие `perm_activity{granted}`). Разрешено → `startBackgroundTracking` уже вызывается → галочка → O3.
* «Не сейчас» → S1 без системного диалога (чтобы не сгорела попытка запроса).
* Отказ «навсегда» = Android не показал диалог (`shouldShowRequestPermissionRationale == false` после отказа). Нужен метод платформы `openAppSettings` (§11).
* Нет датчика (`sensorAvailable == false`): экран пропускается, на O4 вместо «необязательно» — `onbHcRequired`.

### 4.3 O3 · Уведомления

| Элемент | Ключ | Текст |
|---|---|---|
| Заголовок | `onbNotifyTitle` | Утро начинается с мысли |
| Текст | `onbNotifyBody` | Каждое утро — мысль стоика и пара строк от Сергея. Днём — 1–3 вести с дороги. Ночью тишина. |

### 6.1 Компонент `CoachTour` / `CoachTip` (`ui/widgets/coach_tour.dart`)

| T5 | `tab_hero` | вкладка «Герой» нижнего бара | **Рюкзак и снаряжение** · Во вкладке «Герой» — вещи, перки и еда. Есть горелка? Жми «Нагреть»: вода и чай дадут ещё и тепло. | сразу, последняя | «Понятно, идём» → `tourDone = true` | да |

### 6.4 Правила подсказок по случаю

1. Условия — **по состоянию**, а не по событию: проверяются при каждом построении главной / экрана события (так подсказка не теряется, если приложение закрыли в момент случая).
2. Не раньше, чем общий тур завершён или пропущен; не чаще одной за показ экрана; через 600 мс после того, как экран устоялся и прошла синхронизация шагов.
3. Не поверх диалогов, листов, экранов переполнения рюкзака и остановок (`ModalRoute.of(context)?.isCurrent == true`).
4. Приоритет при совпадении: T8 → T6 → T7 → T4* → Z1/Z2. Остальные ждут следующего показа экрана.
5. Каждая — один раз: id пишется в `tourStepSeen` в момент показа.
6. `tipsEnabled == false` — подсказки по случаю не показываются (общий тур это не затрагивает).

### 6.5 Повтор из настроек (N1)

В Настройках (раздел «Подсказки и помощь», правка в файле Интерфейс-1):
* «Показать подсказки снова» → `tourDone = false`, `tourStepSeen = {}`, `tipsEnabled = true`, снэкбар «Подсказки покажутся снова на главном экране.», событие `tour_replay`. Общий тур начнётся при следующем показе главной.
* «Как играть» → слайды I1–I6 в режиме просмотра (`intro_replay`).
* «Перечитать пролог» → страницы пролога (только чтение).

### 7.2 Возврат на шаг

«←» и системное «Назад»: O1 → I6 (если вступление было в этой сессии) или выход; O2 → O1 (данные сохранены); O3 → O2 (если не пропускался, иначе дальше назад); O4 → O3; O5 → O4; O6 вкладка «Еда» → вкладка «Снаряжение» → O5; O7 стр. N → N−1, со стр. 1 → O6 (выбор сохранён). С F1 назад нельзя (путь начат): «Назад» = «Осмотреться». Пропущенные экраны при возврате тоже пропускаются.

### 7.3 Разрешения

| Ситуация | Поведение |
|---|---|
| Активность: отказ | S1: «Спросить ещё раз» · «Подключить Health Connect» → O4 (обязательный) · «Продолжить без шагов» → O5 |
| Активность: отказ «навсегда» | S1 с `onbActBlocked` и «Открыть настройки»; по возврату из настроек — перепроверка |
| Нет датчика | O2 пропускается; O4 с `onbHcRequired`; если и HC нет — O5 с S2 |
| Уведомления: отказ | снэкбар `onbNotifyDenied`, дальше; в настройках остаётся «Разрешить уведомления» |
| HC не установлен | «Установить» → магазин; вернулись — статус перечитан; не поставили — «Пропустить» |
| Шагов нет совсем | можно идти дальше; на главной — существующая плашка «Шаги не поступают» / `stepsOffBanner` |

### 7.4 Сброс пути («Начать путь заново»)

Сохраняются: `introDone`, имя, почта, согласие, `stepsSensor/stepsHc`, `tourDone`, `tourStepSeen`, `tipsEnabled`. Сбрасываются: `loadoutDraft = null`, `onboardingStep = 'loadout'`, `prologueRead = false`, `prologuePage = 0`, `firstStepDone = false`. После сброса: O6 → O7 → F1 → главная без общего тура.

### 7.5 Действующие тестеры (миграция)

Профиль без новых полей и `onboarded == true` → `introDone = true`, `onboardingStep = ''`, `firstStepDone = true`, `tourDone = false` (главная поменялась — тур покажем один раз, его можно пропустить), `tipsEnabled = true`. Рюкзак им не показываем (герой уже в пути; стартовое снаряжение — миграция движка). Профиль с именем и согласием, но без героя → `introDone = true`, `onboardingStep = 'perm_activity'`.

## 10. Доступность

* Зоны нажатия ≥ 48 dp (степперы, «Пропустить», кнопки на карте подсказки). Главные кнопки 52 dp.
* Контраст: текст `#E9DFC8` на `#0E1621` ≈ 13:1; вторичный `#9BA7B4` ≈ 7:1; бирюза `#3FD6CC` ≈ 10:1; тёмный текст на бирюзовой кнопке ≈ 10:1. Цвет не единственный носитель смысла: красная зона — ещё и «!» у названия, риск — значок и слово, выбранная вещь — рамка + «Взято».
* TalkBack: слайд читается как «Слайд n из 6. Заголовок. Абзац. Факт» (`MergeSemantics`), иллюстрация — `introSlideNAlt`. Подсказка тура — модальная (`BlockSemantics` под затемнением), фокус переходит на карточку, объявление «Подсказка {n} из {total}: заголовок. Текст»; цель получает подпись `Semantics(label: …)` от своего виджета. Степпер: «Хлеб, 2 из 3, увеличить / уменьшить». Полоса этапов — «Этап {n} из {total}: {name}».
* Крупный шрифт (до 200 %): все экраны прокручиваются, кнопки закреплены; витраж уменьшается до 28 % высоты; подсказка тура переходит в нижнюю карточку (§6.1); плашки-факты переносятся.
* `MediaQuery.disableAnimations`: без листания с анимацией, без пульса рамки, без полёта вещи в ячейку.
* Вибрация — только на запрет (лимит рюкзака), `HapticFeedback.lightImpact`.
* Тексты без канцелярита, на «ты», мужской род для Сергея; длина: абзац слайда ≤ 140 знаков, текст подсказки ≤ 120 (проверено).
